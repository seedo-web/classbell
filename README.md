# 🔔 클래스벨 (ClassBell)

**초등교사를 위한 교실 수업 도우미** — 시계·타이머·수업 알림·발표 뽑기·좌석배치표·급식·날씨를 설치 없는 4MB 프로그램 하나로. 담임 선생님도, 교과전담 선생님도 이 하나면 됩니다.

📥 **[최신 버전 다운로드](../../releases/latest)**

## 🏠 담임 모드 · 📚 교과전담 모드

첫 실행에서 내 역할을 고르면 앱 전체가 거기에 맞춰집니다. 설정에서 언제든 전환할 수 있고, 명단·좌석배치·뽑기 기록이 전환을 따라 함께 이동합니다.

| | 🏠 담임 (우리 반 하나) | 📚 교과전담 (여러 반) |
|---|---|---|
| **시간표** | 교시별 과목 입력 | 교시별 어느 반 수업인지 지정 |
| **수업 알림** | "3교시 수학 수업이 곧 시작됩니다" | "3교시 4-1 수업이 곧 시작됩니다" |
| **발표 뽑기** | 우리 반 번호/이름 명단 | 지금 수업 중인 반으로 자동 전환, 뽑힌 기록도 반별로 |
| **좌석배치표** | 우리 반 자리 | 반마다 따로 — 수업 들어가면 그 반 자리표가 자동으로 |

## 주요 기능

| | |
|---|---|
| 🕐 **전자시계** | 창 크기 따라 커지는 시계, 더블클릭 전체화면, 다음 수업 카운트다운 |
| ⏳ **타이머** | 디지털/파이(구글 타이머식) · 활동명 표시 · 더블클릭 전체화면 집중 모드 · 1분 전 경고색, 10초 전 깜빡임 · 종료 후 5초 뒤 자동 복귀 |
| 📚 **수업 알림** | 요일별 시간표 등록 → 수업 시작 전 전체화면 카운트다운 알림 · 표시할 모니터 지정(전자칠판) · 교과(전담) 수업은 더 일찍·다른 문구로 · 시작/종료 차임 |
| 🎲 **발표 뽑기** | 번호 또는 이름 명단, 룰렛 애니메이션·효과음·색종이, 한 번 뽑힌 학생 제외 — 동명이인도 정확하게 |
| 🪑 **좌석배치표** | 클릭으로 자리 교환, 두 번 클릭으로 통로, 무작위 자리 섞기, 8색 모둠 칠하기, 학생 시점 방향 전환, 전체화면 크게 보기, A4 한 장 인쇄 |
| 🍚 **급식 · ⛅ 날씨** | 나이스 급식(학교 검색 한 번이면 끝)과 오늘 날씨 자동 조회 |
| ✨ **바탕화면 위젯** | 위 기능들을 작은 위젯으로 항상 화면에 — 항상 위(HUD) ↔ 바탕화면 모드, 드래그·크기·투명도, 위치 자동 기억 |
| ⌨️ **플로팅 바 · 단축키** | 화면에 떠 있는 아이콘 바(안 쓰면 흐려짐)와 전역 단축키 `Ctrl+Shift+0~7`로 위젯을 원클릭 토글 |
| 💾 **데이터 백업** | 명단·시간표·자리 등 모든 설정을 클릭 한 번으로 백업·복구 — 컴퓨터를 바꿀 때도 그대로 |

트레이 상주(창을 닫아도 알림 유지), Windows 시작 시 자동 실행, 다크/라이트 테마, 그리고 자동 업데이트 — 새 버전이 나오면 앱 안에서 클릭 한 번으로 갱신됩니다.

## 설치 (윈도우 10/11)

1. [Releases](../../releases/latest)에서 **`ClassBell.exe`** 를 내려받습니다
2. 더블클릭하면 끝 — 설치 과정 없는 포터블 프로그램입니다
3. 처음 실행 시 "Windows의 PC 보호" 파란 창이 뜨면 **추가 정보 → 실행** (서명 인증서 없는 개인 제작 프로그램에 항상 뜨는 표준 안내입니다)
4. 설정 탭에서 "Windows 시작 시 자동 실행"을 켜두면 매일 아침 알아서 켜집니다

맥(Apple Silicon)은 `ClassBell-*-macos-arm64.zip`을 받아 압축 해제 후 ClassBell.app을 우클릭 → 열기로 실행하세요.

## 자주 묻는 질문

- **문제가 있어요** → 먼저 설정 탭에서 버전을 확인하고 "업데이트 확인"을 눌러 최신인지 확인해 주세요
- **알림을 전자칠판에만 띄우고 싶어요** → 시간표 탭 → 수업 알림 → 알림 표시 위치에서 모니터 선택 (선택 즉시 그 화면에 확인 배너가 뜹니다)
- **담임인데 전담 수업 알림이 필요해요** → 담임 모드 시간표에서 해당 교시의 "교과"에 체크하면 더 일찍, 다른 문구로 알려줍니다
- **교과벨(SubjectBell)을 쓰고 있었어요** → 교과벨은 클래스벨 v2의 교과전담 모드로 통합되었습니다. 클래스벨을 받아 첫 화면에서 교과전담을 선택하세요
- **내 데이터는 어디로 가나요** → 시간표·명단·자리 배치는 전부 이 컴퓨터 안에만 저장되고 외부로 전송되지 않습니다. 설정 탭의 데이터 백업으로 언제든 내보내고 되살릴 수 있습니다
