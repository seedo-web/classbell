# 🔔 클래스벨 (ClassBell)

**초등교사를 위한 교실 수업 도우미**입니다. 시계·타이머·수업 알림·알림장·발표 뽑기·자리 배치·미션·화면 판서·PDF 필기를 설치 없는 프로그램 하나로 씁니다. 담임 선생님도, 교과전담 선생님도 쓸 수 있습니다.

📥 **[최신 버전 다운로드](https://github.com/seedo-web/classbell/releases/latest)** · [변경 내역](https://github.com/seedo-web/classbell/releases) · [문제 제보·기능 제안](https://github.com/seedo-web/classbell/issues)

## 시작하기

### Windows 10/11 (x64)

1. [최신 릴리스](https://github.com/seedo-web/classbell/releases/latest)에서 `ClassBell-버전-windows-x64-portable.zip`을 내려받아 압축을 풉니다.
2. `ClassBell.exe`를 실행합니다. 설치 과정은 없습니다. Microsoft Edge WebView2 런타임을 쓰는데, Windows 11과 대부분의 Windows 10에는 이미 들어 있습니다.
3. "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르세요. 개인이 만든 앱이라 뜨는 경고입니다. 이 저장소의 릴리스에서 받은 파일인지 확인하세요.
4. 첫 화면에서 **담임** 또는 **교과전담**을 고르면 시작합니다.

### macOS (Apple Silicon, macOS 11 이상)

`ClassBell-버전-macos-arm64.zip`을 풀고 `ClassBell.app`을 실행합니다. "열 수 없음" 창이 뜨면 ZIP 안 `README.txt`의 순서(시스템 설정 → 개인정보 보호 및 보안 → **그래도 열기**)를 따라 주세요.

### 업데이트

새 버전이 나오면 앱 안에서 알려 주고, 누르면 내려받아 교체한 뒤 다시 시작합니다. Windows 실행 파일은 서명을 확인한 뒤에만 교체하며, 실패하면 이전 파일로 되돌립니다.

직접 교체할 때는 먼저 **설정 → 앱 완전 종료**(또는 트레이 아이콘 우클릭 → 종료)로 끄세요. 창만 닫으면 트레이에 남아 알림이 계속 동작합니다.

## 🏠 담임 모드 · 📚 교과전담 모드

설정에서 언제든 바꿀 수 있고, 명단·자리·뽑기 기록이 함께 따라옵니다.

| | 🏠 담임 (우리 반 하나) | 📚 교과전담 (여러 반) |
|---|---|---|
| 시간표 | 교시별 과목 입력 | 교시별 어느 반 수업인지 지정 |
| 수업 알림 | "3교시 수학 수업이 곧 시작됩니다" | "3교시 4-1 수업이 곧 시작됩니다" |
| 발표 뽑기 | 우리 반 명단 | 지금 수업 중인 반으로 자동 전환, 기록도 반별로 |
| 자리표 | 우리 반 자리 | 반마다 따로, 수업 시간에 그 반 자리표가 자동으로 |

## 주요 기능

### ⏰ 시계·타이머
- 창 크기에 맞춰 커지는 전자시계, 더블클릭 전체화면, 다음 수업까지 남은 시간
- 디지털·파이(남은 시간이 원판으로 줄어드는 방식) 타이머, 활동명 표시, 자주 쓰는 시간 버튼, ±1분
- 끝나기 1분 전 경고색, 10초 전 깜빡임, 종료 알림

### 📚 시간표·수업 알림
- 월~금 요일별 시간표. 빠른 생성으로 뼈대를 만들고 다른 요일에 복사할 수 있습니다.
- **오늘만 바꾸기**: 행사·단축 수업일에 오늘 시간표만 바꾸면 다음 날 원래대로 돌아옵니다.
- 수업 시작 전 **전체화면 카운트다운**(또는 상단 배너)과 차임. 알림 띄울 모니터를 고를 수 있어 전자칠판에만 띄울 수 있습니다.
- 담임 시간표에서 "교과"에 체크한 수업(전담·이동 수업)은 더 일찍 알려 줍니다.
- 판서로 필기하는 중에는 필기를 가리지 않게 배너로 알리고, 마우스 모드이거나 판서를 접었을 때는 전체화면으로 알립니다.

### 📝 알림장
- 작성하면 자동 저장. 수업 알림과 같은 모니터에 고대비 전체화면으로 크게 띄웁니다.
- 띄워 둔 채로 내용을 고치면 화면에 바로 반영됩니다.

### 🎲 발표 뽑기
- 학생 또는 모둠 뽑기, 한 번에 여러 명. 효과음·애니메이션, 뽑힌 학생 제외. 동명이인도 구별합니다.
- **이름판 뽑기**: 가려진 카드를 학생이 직접 골라 뒤집습니다. '이름 순서 섞기'로 다시 가리고 섞습니다.
- 오늘 결석 제외, 마지막 뽑기 취소, 기록 한 건 삭제

### 🪑 자리 배치·학생 관리
- **조건 자리 섞기**: 남녀 짝, 모둠 성비, 이전 짝·모둠 피하기, 학습 지원·친한 친구 분산 조건을 켜고 중요도를 조절합니다. 결과는 자리판 곳곳에서 한 명씩 공개됩니다(바로 보기 가능).
- 고정석·짝·모둠·책상 위치 조절, 이전 배치와 비교·되돌리기, 담임이 직접 바꾼 뒤 '배치 점검'
- 모둠 색 12가지, 학생 시점 방향 전환, 크게 보기, A4 한 장 인쇄
- 설정의 **학생 관리**에서 번호·이름·성별·학습 지원·친구 관계·교사용 메모를 한곳에서 관리하고, 뽑기·자리표·미션이 같은 명단을 씁니다.

### ✅ 미션 (아침활동·학습활동)
- 오늘 할 일을 전체화면에 크게 띄우고, 학생이 자기 이름 버튼을 눌러 완료를 체크합니다. 최대 40명이 스크롤 없이 한 화면에 나옵니다.
- 아침활동에는 우유 확인 버튼을 따로 켤 수 있습니다.
- 그날 체크는 다시 열어도 유지되고, 다음 날 체크만 초기화됩니다. 결석 학생은 목록에서 빠집니다.
- 교사 화면에서 완료한 학생을 한눈에 봅니다. 인터넷 없이 동작합니다.

### 🖍️ 칠판·화면 판서
- 칠판 아이콘(또는 `Ctrl+Shift+D`)으로 화면 위에 바로 필기하고, 다시 누르면 저장한 채로 접습니다.
- 펜·붓·형광펜·부분 지우개·선택·도형·글자, 내 색상, 손가락 멀티터치, 펜 전용 모드
- **마우스 모드**로 바꾸면 필기를 화면에 남겨 둔 채 아래 프로그램을 조작할 수 있습니다.
- 필기할 모니터 선택, 도구막대 위치 이동·기억

### 📄 PDF 교재 필기
- 축소판으로 페이지를 보고 범위를 골라 가져옵니다(한 번에 최대 20쪽, 파일당 20MB 이하).
- 50~400% 확대·축소, 화면 맞춤, 이동. 문서별로 페이지를 묶어 닫았다가 다시 열 수 있고, 필기는 유지됩니다.

### 🍚 급식·⛅ 날씨·✨ 위젯
- 급식은 처음에 학교 이름을 한 번 검색해 고르면 매일 자동으로 보여 줍니다(나이스 교육정보 개방 포털). 날씨는 지역만 고르면 됩니다.
- 시계·미니 타이머·다음 수업·뽑기·급식·날씨·자리표를 작은 위젯으로 띄웁니다. 항상 위(HUD)와 바탕화면 모드, 드래그·크기 조절, 위치 자동 기억
- 위젯 배치를 장면으로 저장해 두었다가 한 번에 불러올 수 있습니다.

### ⚙️ 그 밖에
- 트레이 상주(창을 닫아도 알림 유지), Windows 시작 시 자동 실행, 다크/라이트 테마

## ⌨️ 단축키

어느 프로그램을 쓰고 있어도 동작합니다. 다른 앱이 먼저 쓰고 있는 키는 등록되지 않으며, 등록 결과는 설정의 단축키 표에서 볼 수 있습니다.

| 단축키 | 기능 |
|---|---|
| `Ctrl+Shift+D` | 판서 열기 / 판서 ↔ 마우스 모드 전환 |
| `Ctrl+Shift+0` | 플로팅 위젯 바 |
| `Ctrl+Shift+1`~`7` | 위젯 켜기·끄기 (1 시계 · 2 타이머 · 3 다음 수업 · 4 뽑기 · 5 급식 · 6 날씨 · 7 자리표) |

판서 안에서 쓰는 키:

| 단축키 | 기능 |
|---|---|
| `PageUp` / `PageDown` | 이전 / 다음 페이지 (PDF 포함) |
| `Ctrl+Z` / `Ctrl+Shift+Z` | 실행 취소 / 다시 실행 |
| `Delete` | 선택한 것 지우기 |
| `+` / `−` | 선택한 것 확대·축소 |
| `Ctrl+S` | 현재 페이지 PNG로 저장 |
| `F1` | 도움말 |
| `Esc` | 메뉴·선택 닫기, 마우스 모드로 |

## 💾 데이터와 백업

- 시간표·명단·자리·알림장·판서는 **모두 이 컴퓨터 안에만 저장**됩니다. 인터넷으로 나가는 것은 급식(학교 코드)·날씨(지역 좌표) 조회와 업데이트 확인뿐입니다.
- 백업은 두 가지입니다.
  - **설정 → 데이터 백업**: 설정·명단·시간표·자리·알림장·위젯 배치
  - 칠판의 **페이지 → 판서 파일 저장**: 원본 PDF와 필기
- 미션의 안내문과 체크 기록은 아직 설정 백업에 들어가지 않습니다.
- 실행 파일만 다른 PC로 복사하면 데이터는 옮겨지지 않습니다. 위 두 백업 파일을 함께 옮겨 불러오세요.

## ❓ 자주 묻는 질문

- **알림을 전자칠판에만 띄우고 싶어요** → 시간표 → 수업 알림 → 알림 표시 위치에서 모니터를 고르세요. 고르는 즉시 그 화면에 확인 배너가 뜹니다.
- **알림이 1번 모니터에 떠요** → 화면을 '복제'로 쓰면 모니터가 1대로 인식되어 주 모니터에 뜨는 것이 정상입니다. '확장'으로 쓰면 번호를 고를 수 있습니다.
- **다른 선생님께 드려도 되나요?** → 네. 새로 받은 클래스벨에는 학교·명단이 비어 있고, 각자 자기 학교를 검색해 설정합니다.
- **교과벨(SubjectBell)을 쓰고 있었어요** → 교과벨은 클래스벨의 교과전담 모드로 통합되었습니다.
- **문제가 생겼어요** → 설정에서 버전을 확인하고 '업데이트 확인'으로 최신인지 본 뒤, [Issues](https://github.com/seedo-web/classbell/issues)에 버전과 함께 남겨 주세요.

## 알려진 한계

- 실제 전자칠판의 필압·손날 지우개, 여러 물리 모니터 배치는 장비마다 다를 수 있습니다. 손날 지우개는 접촉 크기 정보를 주는 장비에서만 동작합니다.
- 저해상도 스캔 PDF는 확대해도 원본보다 선명해지지 않습니다.
