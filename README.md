# 클래스벨 (ClassBell)

초등교사를 위한 설치 없는 교실 수업 도우미입니다. 담임·교과전담 모드를 지원합니다.

**[최신 버전 다운로드](https://github.com/seedo-web/classbell/releases/latest)**

## 실행 방법

- **Windows:** `windows-x64-portable.zip`을 내려받아 압축을 풀고 `ClassBell.exe`를 실행하세요. WebView2 Runtime이 필요합니다.
- **macOS Apple Silicon:** `macos-arm64.zip`을 내려받아 압축을 풀고 `ClassBell.app`을 실행하세요.
- 기존 파일을 교체할 때는 **설정 → 앱 완전 종료**로 먼저 종료하세요.

## 주요 기능

| 기능 | 내용 |
|---|---|
| 시계·타이머 | 전자시계, 디지털·파이 타이머, 종료 알림 |
| 시간표·수업 알림 | 요일별 시간표, 시작 전 알림, 시작·종료 차임 |
| 알림장 | 작성·저장, 전자칠판에 크게 표시 |
| 발표 뽑기·자리 배치 | 학생·모둠 뽑기, 자리 교환·섞기·인쇄 |
| 칠판·PDF 판서 | 화면 위 필기, 선택·지우개·도형·글자, PDF 확대·페이지 이동 |
| 급식·날씨·위젯 | 급식·날씨 조회, 바탕화면 위젯 |

칠판 아이콘을 누르면 판서를 열고, 다시 누르면 저장한 상태로 숨깁니다. PDF는 파일당 20MB 이하, 한 번에 최대 20쪽을 불러올 수 있습니다.

## 데이터 백업

설정·명단·시간표는 **설정 → 데이터 백업**에서, 판서·PDF는 칠판의 **페이지 → 판서 파일 저장**에서 각각 백업하세요. 실행 파일만 복사하면 데이터는 옮겨지지 않습니다.
