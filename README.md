# 🔔 클래스벨 (ClassBell)

**초등교사를 위한 교실 수업 도우미** — 시계·타이머·수업 알림·알림장·발표 뽑기·좌석배치표·화면 판서·PDF 교재 필기를 설치 없는 프로그램 하나로. 담임 선생님도, 교과전담 선생님도 이 하나면 됩니다.

📥 **[최신 버전 다운로드](../../releases/latest)**

현재 정식 버전은 **[v2.5.0](../../releases/tag/v2.5.0)**입니다. Windows 화면 위 판서와 PDF 교재 필기를 클래스벨에 통합했습니다.

## 🏠 담임 모드 · 📚 교과전담 모드

첫 실행에서 내 역할을 고르면 앱 전체가 거기에 맞춰집니다. 설정에서 언제든 전환할 수 있고, 명단·좌석배치·뽑기 기록이 전환을 따라 함께 이동합니다.

| | 🏠 담임 (우리 반 하나) | 📚 교과전담 (여러 반) |
|---|---|---|
| **시간표** | 교시별 과목 입력 | 교시별 어느 반 수업인지 지정 |
| **수업 알림** | "3교시 수학 수업이 곧 시작됩니다" | "3교시 4-1 수업이 곧 시작됩니다" |
| **발표 뽑기** | 우리 반 번호/이름 명단 | 지금 수업 중인 반으로 자동 전환, 뽑힌 기록도 반별로 |
| **좌석배치표** | 우리 반 자리 | 반마다 따로 — 수업 들어가면 그 반 자리표가 자동으로 |

## 실행 방법

### Windows 포터블

1. [최신 릴리스](../../releases/latest)에서 **`ClassBell-2.5.0-windows-x64-portable.zip`**을 내려받아 압축을 풉니다.
2. **`ClassBell.exe`**를 실행합니다. 별도 설치 과정은 없으며, WebView2 Runtime이 필요합니다. 현재 정식판의 검수 환경은 Windows 11 x64입니다.
3. 설정에서 **Windows 시작 시 자동 실행**을 선택할 수 있습니다.
4. 교체 실행할 때는 기존 클래스벨을 **설정 → 앱 완전 종료**로 종료하세요. 창만 닫으면 트레이에 남아 알림이 계속 동작할 수 있습니다.

릴리스의 `ClassBell.exe`를 직접 내려받아도 됩니다. 개인 제작 앱이므로 Windows 실행 경고가 표시될 수 있습니다. 공식 저장소의 배포 파일인지 확인하세요.

macOS Apple Silicon은 `ClassBell-2.5.0-macos-arm64.zip`을 받아 압축 해제 후 `ClassBell.app`을 실행하세요.

## 칠판과 PDF 사용하기 · 2.5.0

- 클래스벨의 **칠판 아이콘**을 누르면 판서를 열고, 다시 누르면 저장한 상태로 숨깁니다.
- **화면**에서 필기할 모니터를 선택하고, **마우스**로 전환하면 아래 프로그램을 조작할 수 있습니다.
- **도구 → PDF 열기**에서 축소판을 확인하고 시작·끝 페이지를 지정합니다. 한 번에 **최대 20쪽**, 파일은 **20MB 이하**입니다. 축소판 클릭과 Shift+클릭으로도 범위를 선택할 수 있습니다.
- PDF는 문서별로 묶입니다. **문서 닫기/전체 닫기**로 한 번에 숨기고 페이지 목록에서 다시 열 수 있습니다. 필기는 유지됩니다.
- PDF는 **50~400% 확대·축소**, 화면 맞춤, 이동을 지원합니다. 저해상도 스캔 원본 자체를 고화질로 바꾸지는 않습니다.

| 단축키 | 기능 |
|---|---|
| `Ctrl+Shift+D` | 판서 시작 및 마우스/판서 모드 전환 |
| `PageUp` / `PageDown` | 이전/다음 열린 판서 페이지로 이동(PDF 포함) |
| `+` / `−` | 선택한 객체 확대·축소 |
| `Delete` | 선택한 객체 삭제 |
| `Ctrl+Z` / `Ctrl+Shift+Z` | 실행 취소 / 다시 실행 |

손가락 멀티터치 입력을 지원합니다. 실제 전자칠판의 필압·손날 지우개와 여러 물리 모니터 동작은 장비별 확인이 필요합니다. 손날 지우개는 접촉 크기 정보를 제공하는 장비에서 설정 후 사용할 수 있습니다.

### 판서 백업과 베타에서 이동

**클래스벨 설정 백업과 판서 백업은 별개입니다.** 판서의 **페이지 → 판서 파일 저장**으로 원본 PDF와 필기를 포함한 JSON 파일을 저장하고, **판서 파일 열기**로 복원하세요. EXE만 다른 PC로 복사하면 설정과 판서 데이터는 옮겨지지 않습니다.

베타판과 정식판은 저장 공간이 다릅니다. 베타에서 판서 파일을 내보낸 뒤 정식판에서 불러오세요. 이전 베타에서 이미지로 가져온 PDF는 원본 PDF를 다시 불러와야 새 렌더링 방식을 사용합니다.

## 로컬 검수 중인 개선 사항 · 미배포

아래 기능은 **현재 공개된 2.5.0 다운로드에는 포함되지 않습니다.** 별도 검수 후 배포 여부를 결정합니다.

- PDF 축소판을 손가락으로 드래그하여 범위 선택·가장자리 자동 스크롤
- 글자 입력창에서 크기 조절·미리보기
- PDF 도구를 오른쪽에 배치
- 하단 판서 도구막대 이동·위치 기억·초기화
- 휴지통 아이콘과 터치 영역 확대

알림 중복 현상은 원인 분석 단계입니다. 앱 재실행 시 사전 알림 재발화와 서로 다른 알림 시각이 겹칠 때 차임을 각각 호출하는 경로를 확인했으며, 이에 대한 수정은 아직 배포하지 않았습니다.

## 자주 묻는 질문

- **문제가 있어요** → 먼저 설정 탭에서 버전을 확인하고 "업데이트 확인"을 눌러 최신인지 확인해 주세요
- **알림을 전자칠판에만 띄우고 싶어요** → 시간표 탭 → 수업 알림 → 알림 표시 위치에서 모니터 선택 (선택 즉시 그 화면에 확인 배너가 뜹니다)
- **담임인데 전담 수업 알림이 필요해요** → 담임 모드 시간표에서 해당 교시의 "교과"에 체크하면 더 일찍, 다른 문구로 알려줍니다
- **교과벨(SubjectBell)을 쓰고 있었어요** → 교과벨은 클래스벨 v2의 교과전담 모드로 통합되었습니다. 클래스벨을 받아 첫 화면에서 교과전담을 선택하세요
- **내 데이터는 어디로 가나요** → 시간표·명단·자리 배치는 전부 이 컴퓨터 안에만 저장되고 외부로 전송되지 않습니다. 설정 탭의 데이터 백업으로 언제든 내보내고 되살릴 수 있습니다
